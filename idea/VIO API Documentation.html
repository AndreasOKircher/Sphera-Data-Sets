Introduction

Welcome to the VIO API documentation. This comprehensive API provides access to VIO's AI capabilities, including chat completions, model management, file operations, and embeddings. The API is designed to be both powerful and flexible, with OpenAI-compatible endpoints for easy integration.

Authentication

The VIO API uses token-based authentication. Different endpoints support different authentication methods:

Bearer Token

For OpenAI-compatible endpoints (/chat/completions, /models, /embeddings)

Authorization: Bearer your_api_token

Body Parameters

For VIO management endpoints (model and file operations)

{
  "username": "your_username",
  "token": "your_api_token"
}

How to create a token?

Open VIO Application

Launch the VIO desktop application

Go to API Settings

Navigate to 🔌 VIO API

Generate Token

Create and manage your API tokens

Important

Once you have generated a token, make sure to set it as the API_TOKEN environment variable in your system or application configuration.

Example .env file 
API_USERNAME=your_username
API_TOKEN=your_api_token

Base URL

All API requests should be made to the following base URL:

VIO API Base URL 
https://vio.automotive-wan.com:446

Example Usage

Append the endpoint path to the base URL. For example, to access chat completions:

https://vio.automotive-wan.com:446/chat/completions

API Endpoints

The VIO API provides comprehensive endpoints for AI interactions and VIO management. Endpoints marked with OpenAI Compatible can be used with standard OpenAI SDKs and tools.

Chat & AI Endpoints

POST /chat/completions OpenAI Compatible

Send chat completion requests to VIO models or direct LLM models. Supports streaming responses and OpenAI tool calling.

Request Headers 
Authorization: Bearer your_api_token
Content-Type: application/json
Request Body 
{
  "model": "Default",
  "messages": [
    {"role": "system", "content": "You are a helpful assistant."},
    {"role": "user", "content": "Hello, how are you?"}
  ],
  "stream": false,
  "tools": [  // Optional: OpenAI-compatible tool calling
    {
      "type": "function",
      "function": {
        "name": "get_weather",
        "description": "Get the current weather",
        "parameters": {
          "type": "object",
          "properties": {
            "location": {"type": "string", "description": "City name"}
          },
          "required": ["location"]
        }
      }
    }
  ],
  "tool_choice": "auto"  // Optional: auto, none, or specific function
}
Response Body 
{
  "id": "chatcmpl-123",
  "object": "chat.completion",
  "created": 1677858242,
  "model": "Default",
  "choices": [
    {
      "index": 0,

        "role": "assistant",
        "content": "Hello! I'm doing well, thank you for asking."
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 13,
    "completion_tokens": 12,
    "total_tokens": 25

}

Using Direct LLM Model 
{
  "model": "VIO:GPT-4o",  // Prefix with "VIO:" to bypass VIO prompts
  "messages": [
    {"role": "system", "content": "You are a helpful assistant."},
    {"role": "user", "content": "Hello!"}
  ],
  "stream": false
}
Note: Models prefixed with "VIO:" bypass VIO-specific prompts and RAG capabilities, sending messages directly to the LLM.

POST /embeddings OpenAI Compatible

Using OpenAI SDK

The OpenAI-compatible endpoints can be used directly with the OpenAI SDK:

Python Example 
import openai

client = openai.OpenAI(
    api_key="your_vio_api_token",
    base_url="https://contivity.aws3116.ec1.aws.automotive.cloud:446/"
)

# Chat completion
response = client.chat.completions.create(
    model="Default",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Explain quantum computing"}
    ]
)
print(response.choices[0].message.content)

# Streaming
stream = client.chat.completions.create(
    model="Default",
    messages=[{"role": "user", "content": "Write a story"}],
    stream=True
)
for chunk in stream:
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="")
JavaScript Example 
import OpenAI from 'openai';

const openai = new OpenAI({
  apiKey: 'your_vio_api_token',
  baseURL: 'https://contivity.aws3116.ec1.aws.automotive.cloud:446/'
});

const completion = await openai.chat.completions.create({
  model: 'Default',
  messages: [
    { role: 'system', content: 'You are a helpful assistant.' },
    { role: 'user', content: 'Explain quantum computing' }
  ]
});

console.log(completion.choices[0].message.content);
Curl Example 
curl https://contivity.aws3116.ec1.aws.automotive.cloud:446/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer your_vio_api_token" \
  -d '{
    "model": "Default",
    "messages": [
      {"role": "system", "content": "You are a helpful assistant."},
      {"role": "user", "content": "Explain quantum computing"}
    ]
  }'

VIO Model Management

Create, edit, and delete custom VIO models with specific configurations.

POST /create_vio_model

Create a new VIO model with custom settings and AI model selection.

Request Body 
{
  "type": "CREATE_VIO_MODEL",
  "username": "your_username",
  "token": "your_api_token",
  "name": "MyVioModel",
  "description": "A custom VIO model",
  "is_public": false,
  "is_token_protected": false,
  "ai_model": "Default"
}
Response Body 
{
  "message": "VIO model created."
}
PUT /edit_vio_model

Edit an existing VIO model's properties including name, description, and visibility.

Request Body 
{
  "type": "EDIT_VIO_MODEL",
  "username": "your_username",
  "token": "your_api_token",
  "original_name": "MyVioModel",
  "changed_name": "RenamedModel",
  "description": "Updated description",
  "is_public": true,
  "is_token_protected": false,
  "ai_model": "GPT-4o"
}
Response Body 
{
  "message": "VIO model updated."
}
DELETE /delete_vio_model

Delete a VIO model permanently.

Request Body

  "token": "your_api_token",
  "name": "ModelToDelete"
}
Response Body 
{
  "message": "VIO model 'ModelToDelete' deleted."

File Management

Upload, load, and manage files associated with VIO models for RAG capabilities.

POST /add_file

Upload files to be associated with a specific VIO model.

Form Data 
type: ADD_FILE
username: your_username
token: your_api_token
vio_model: Default
files: [file1.pdf, file2.pdf]  // Multiple files
Response Body 
{
  "message": "File 'file.pdf' added successfully to VIO model 'Default'."
}
POST /load_file

Process and load files for a VIO model to enable RAG capabilities.

Request Body 
{
  "type": "LOAD_FILE",
  "username": "your_username",
  "token": "your_api_token",
  "vio_model": "Default",
  "files": ["file1.pdf", "file2.pdf"],
  "all": false  // Set to true to load all files
}
Response Body 
{
  "message": "Files loaded successfully for VIO model 'Default'."
}
POST /delete_file

Delete files from a VIO model.

Request Body 
{
  "type": "DELETE_FILE",
  "username": "your_username",
  "token": "your_api_token",
  "vio_model": "Default",
  "files": ["file1.pdf", "file2.pdf"],
  "all": false  // Set to true to delete all files
}
Response Body 
{
  "message": "Files deleted successfully from VIO model 'Default'."
}

Docker Usage

When using the VIO API within a Docker container, you need to properly handle SSL certificates for secure communication. Follow these steps:

1. Install Certificate Library

Include the certifi library in your requirements:

requirements.txt 
requests
python-dotenv
certifi
python-certifi-win32

2. Export Certificates

Export necessary certificates from your browser or system and place them in a /Certificat directory:

Certificate Export

Export the required certificates and save them as trusted_certs.crt in your project's /Certificat directory.

your-project/
├── Dockerfile
├── requirements.txt
├── src/
│   └── main.py
└── Certificat/
    └── trusted_certs.crt

3. Update Dockerfile

Modify your Dockerfile to include certificates:

Dockerfile 
FROM python:3.9-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# Create directory for certificates
RUN mkdir -p /Certificat

# Copy certificates
COPY ./Certificat/trusted_certs.crt /Certificat/trusted_certs.crt

COPY ./src /app/src

CMD ["python", "src/main.py"]

4. Configure Certificate Verification

Add certificate handling to your code:

Certificate Setup 
import os
import requests

class VioApiClient:
    def __init__(self):
        self.session = requests.Session()
        self.setup_certificate_verification()
        
    def setup_certificate_verification(self):
        cert_dir = "/Certificat"
        if os.path.exists(cert_dir):
            custom_bundle = os.path.join(cert_dir, "custom_bundle.pem")
            with open(custom_bundle, 'wb') as bundle:
                for cert_file in ["trusted_certs.crt"]:
                    file_path = os.path.join(cert_dir, cert_file)
                    if os.path.exists(file_path):
                        with open(file_path, 'rb') as cert:
                            bundle.write(cert.read())
                            bundle.write(b'\n')
            self.session.verify = custom_bundle

Security Note

Always ensure certificates are properly secured and not exposed in public repositories. Consider using Docker secrets or environment variables for sensitive information in production.
